# UZH teaching rooms we track: the "Zentrum", "Irchel" and "Oerlikon" views of UZH's public
# room calendar (uzh.book.3vrooms.app), i.e. the centrally booked rooms (Hörsaaldisposition).
# One id per line, as UZH spells it (building-floor-room). Built from the calendar of
# 2026-11-20 with uzh.drop_reason(); a fetch logs a warning when the calendar has rooms that are
# missing here, or no longer has rooms that are listed.
#
# Left out on purpose (bookable in the calendar, but not rooms to study in):
#   - Apérofläche, Lager, Küche, Lichthof, Foyer, Mall, Medizinerhof, Bar, Eingangsbereich,
#     Empfang, Dozierendenzimmer, Postersession, the "Vorlage" template and poster/vitrine spots
#   - "EV" rooms (event rooms, e.g. KOL-E-13 EV Senatszimmer), except the ones the course
#     catalogue showed regular teaching in (docs/uzh-validation.md); those are listed below
#   - KOL-G-201 Aula: a standing block "Informationen über die Verfügbarkeit auf Anfrage"
#     (2026-2030), i.e. only bookable on request, so it would always show as busy (uzh.EXCLUDED)
#   - Labor-Praktikumsraum (teaching labs, Y14-F-21, Y14-F-41)
#   - event spaces that only give a capacity in "Personen" (AFL-E-070 Olivenhalle, Y13-G-100)
#   - combinations of rooms that are listed one by one (their bookings show up on the parts):
#     AND-3-02/06, BIN-0-K.11/12, BIN-0-K.12/13, BIN-0-K.11/12/13, KUM-E-1/2/3, Y22-F-62/68,
#     Y22-F-62/70 and Y22-F-62/68/70 (dropped when any part is listed itself)
